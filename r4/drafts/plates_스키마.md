## 0. 이 대장이 지키는 원칙 (왜 이렇게 나눴나)

1. **한 그림 = 한 항목.** 콘택트 시트 번호가 여러 개인 같은 그림(05·10·16 / 24·32 / 00·18)은 항목 하나에 번호를 모두 적는다. 캡션은 항목에서만 나오므로 오기가 한 곳에서만 고쳐진다.
2. **사람이 적는 칸과 기계가 적는 칸을 나눈다.** Met API 에서 그대로 오는 값(영문 작가·영문 제목·연도·재료·objectURL)은 손대지 않고, 한글 번역·쓰이는 페이지·크롭 초점만 사람이 적는다. 그래야 「어디까지가 확인된 사실이고 어디부터가 우리 판단인가」가 파일 안에서 보인다.
3. **캡션에 들어가는 글자는 대장에서만 나온다.** 시안C 에서 손으로 쓴 캡션 5줄(도판 01~05)이 이 대장의 첫 시험 데이터다 — 생성기가 만든 캡션이 지금 화면의 글자와 한 자도 다르지 않아야 한다(확장방안 3절).
4. **원본은 건드리지 않는다.** `art_master/NN.jpg` 는 그대로 두고, 화면용 파일 이름은 대장의 `file` 칸이 정한다.

## 1. 파일 전체 모양

```
{
  "_meta": { ... 대장 자체 정보 ... },
  "plates": [ { ...도판 1점... }, { ... } ]
}
```

- `_meta`: `source`(「메트로폴리탄 미술관 Open Access」), `license`(「Public Domain — CC0」), `verified`(Met API isPublicDomain 재확인 날짜 · 2026-09-30), `filter`(모노톤 CSS 값 한 벌 — `--plate-filter` 변수의 정본. 오너가 "컬러로" 하면 여기 한 줄).
- `plates`: 도판 배열. 순서는 의미 없음(페이지 안 번호 01·02… 는 생성기가 `pages` 칸의 순서로 매긴다 — 아래 §3).

## 3. `pages` 칸 — 어느 페이지 어느 자리에 놓이나

```
"pages": [
  {"page": "index",    "slot": "spread"},
  {"page": "교회소개", "slot": "grid", "order": 2}
]
```

- `page`: 페이지 이름 = 생성기 본문 조각 이름(`index`·`교회소개`·`예배안내`·`새가족`·`아카데미`·`온라인예배`·`재정`·`주보`·`칼럼` — r4 대장 9개와 같은 이름).
- `slot`: `spread`(첫 판면 왼쪽 큰 도판 · 페이지당 1점) 또는 `grid`(도판 목록).
- `order`: grid 안 순서. 생성기는 spread 를 01, grid 를 order 순으로 02·03… 매긴다 → 캡션 번호 「도판 NN」은 손으로 안 적는다.
- 생성기 검사 규칙(코드 전 합의용): ①한 페이지에 spread 는 정확히 1점 ②spread 에 portrait 그림 금지 ③`src_px` 가로 < 2400 인 그림은 spread 금지(24 자동 탈락) ④같은 페이지에 같은 그림 2번 금지.

## 5. 남은 판단 1건 + 해결된 것

1. **★31 안견 — Met 원문은 「Style of An Gyeon」**(`artistPrefix: "Style of"` · API 2026-09-30 실측). 「attributed to(傳)」가 아니라 **「~의 화풍으로」** 다. 그러므로
   - 「안견」 단정형(시안C 현재) ✗ · 「전(傳) 안견」·「안견 전칭」(명화_후보.html 현재) ✗ — 둘 다 Met 표기와 다르다(傳 = attributed 의 번역).
   - 제안: **「안견 화풍」** (또는 「안견 풍」). 어느 쪽 낱말로 할지 master 판단. 결정되면 명화_후보.html 의 「안견 전칭」도 같이 고쳐야 한다(내 산출물 — 지시 있으면 수정).
2. (해결) 04·05 연도 — 붙인다 · Met 원문 그대로 §8 규칙.
3. (해결) 10 제목 — 「소 떼」. 시안C 134행 캡션 수정 완료. **같은 figure 의 alt(133행)에도 「소들」이 남아 있다** — 허가가 「캡션 문자열 1곳」이라 손대지 않았다. 생성기가 만들 때는 alt=캡션 규약이라 자동으로 맞는다. 지금 고칠지 master 판단.
4. (해결) `title_suffix` 신설 · `date_ko` 별도 칸 · 파일명 `art22` 유지 — 승인.
5. (해결) `_meta.filter` 정본값 — 시안C CSS 두 곳(`.plateL img` 45행 · `.grid figure img` 75행) **같은 값** `grayscale(1) sepia(.13) contrast(1.02)`. 옮겨도 화면 변화 0.
