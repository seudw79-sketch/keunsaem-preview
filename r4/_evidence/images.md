## 히어로를 캔바 생성/스톡 대신 자체 질감으로 정한 근거
1. hcbc.kr(1차 벤치마크)의 히어로가 바로 "질감 있는 예배당 벽면 실사 + 캘리 성구" — 같은 문법을 우리 예배당 벽(십자가)으로 구현하면 정체성이 보존된다.
2. 캔바 generate-image 는 이 커넥터에서 200×200 썸네일만 내려받힘(1차 검증 실측) — 1920 폭을 얻으려면 디자인 변환·export 추가 단계가 필요하고, AI 생성 물·빛 이미지는 스톡풍/AI 기믹 위험(design-token-system 스킬 §8 경고).
3. 스톡(Unsplash/Pexels)은 라이선스·작가 표기 관리와 톤 일치가 추가 부담. 자체 사진은 라이선스 0 리스크.
4. 사람 얼굴 0 · 글자 0 · 저채도 · 밝은 톤 — master 금지선 전부 충족.
